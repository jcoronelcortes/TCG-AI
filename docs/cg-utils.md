# Módulo cg.utils

## Propósito

Contiene utilidades genéricas para trabajar con estructuras de datos y serialización.

## Funcionalidades

- Conversión recursiva de diccionarios a dataclasses.
- Conversión de cadenas JSON en bytes a objetos dataclass.

## Uso

Se usa principalmente por [cg.api](cg-api.md) para transformar los datos recibidos del simulador en tipos más manejables desde Python.
