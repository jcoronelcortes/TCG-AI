# Módulo cg.game

## Propósito

Proporciona una capa de acceso a la lógica de batalla del simulador nativo.

## Funcionalidades

- Iniciar una batalla con dos mazos.
- Obtener la observación actual del estado del juego.
- Enviar una selección de acción al motor.
- Finalizar la batalla y liberar recursos.
- Recuperar datos para visualización.

## Consideraciones

Este módulo depende de la librería nativa del simulador y de la inicialización del objeto de batalla compartido.
