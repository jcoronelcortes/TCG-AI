## Four things the plan got wrong, found while executing it

Recording these because the plan was written hours earlier and each was a real
error, not a refinement.

**1. `git archive` does not carry the inputs.** `competitor_decks_500/`,
`cg/build/` and `ptcg_engine/` are all gitignored, so the exported tree could
neither read the 500 decks nor run a seeded game. Fixed by copying them in; the
plan's §6 export line should say so.

**2. `OpponentBot(first_choice="second")` pins us FIRST, not second.** The plan's
M4 asked for a going-second arm using that flag. Measured: `primero 40/40,
segundo sin partidas`. The `IS_FIRST` select reaches seat 0 only, so when the bot
holds seat 0 and declines, *we* open — and when we hold it we answer YES and open
anyway. **On HEAD there is no way to pin ourselves second**, because that requires
the agent to answer NO, which is the pre-`8192c22` code. Consequence: no number
from tonight is comparable *in kind* with the historical going-second figures.

**3. M4 never needed its own games.** `selfplay.accumulate` has always maintained
`cand_primero` / `cand_segundo`; `matchup_matrix.py` simply never printed them.
Surfacing them (a change to `_row`/`_print_row`) gave the seat split for **all 133
matchups** instead of the planned 4 archetypes, at zero CPU. M1 was killed and
relaunched to pick it up — cheap, because the table prints at the end. The split
is **exact**, not approximate: `torneo` alternates by `i % 2`.

**4. The allocation caveat was already solved.** C3 was told to build
`pesos_alloc.csv` so the top-100 summary would not be under-sampled. Unnecessary:
`allocate()`'s floor is `games // 4` = **100 games minimum per deck**, and the
top-100's four heavy hitters land between 900 and 13 000 games. The file was
written and left unused, which is recorded here rather than quietly dropped.

## Why H1 was not run

Q4 permitted agent edits under a written criterion, and A4 produced a ranking. H1
was still not run, and the reason is the night's main finding rather than the
clock: **"stuck WITH an escape available and did not take it" is flat across all
four archetypes** (−2.3 to +4.9), while "stuck with **no** escape" separates
strongly (+8.6 to +29.2). The losses are board and resource starvation, not
misplay. A scoring rule therefore has a low prior against exactly the two
matchups it would have been written for. Running H1 would have measured a
hypothesis the census argues against.

Q7's "zero fixed in flight" already forbade writing rules tonight; A4 turned that
from a scheduling rule into the right call on the merits.

## Judging the premise (the plan's §9)

The plan named two ways to be wrong. **The first came back half true.**

* §9 said the premise fails if *M3 shows the headline unchanged **and** M2's two
  weightings agree archetype by archetype.* M3 did show it unchanged — 94.6 % vs
  94.50 %, prizes +4.063 both. But M2's weightings **do not agree**: Marnie swings
  −16.3 pp between them, Lopunny/Froslass +8.9, and the loss ranking reorders
  completely with Crustle Wall leaving the top-100 table entirely.
* So: the corpus rebuild bought a tighter interval and nothing else for the
  headline. What paid was the **second weighting** and the **archetype-level
  aggregation** — the old corpus fragmented Crustle Wall across too few lists to
  show that it is 8.23 % of the field and the single biggest leak.
* §9's second failure mode (A4's classes failing to separate from control) did
  **not** happen: the classes separated strongly. But the trait that separated was
  the one that says *don't write a rule*.

## The pending list, ranked

1. ⭐ **Build the card-level census** — which of our 60 never gets played in a
   given matchup. It does not exist. Track A says the hard matchups fail through
   starvation, which is what a list change addresses and a scoring rule does not,
   so this is the one instrument that can act on tonight's finding.
2. **Read Ogerpon Verde's losses by hand.** The only archetype with a positive
   "escape not taken" (+4.9), 77.3 % of losing turns with no attacker ready, and
   the top-100's biggest leak. The discovery channel is a human reading a lost
   game.
3. **Crustle Wall as a resource race.** 28 % of its losses are deck-out, unique in
   the corpus; stuck streaks reach 11 consecutive turns against 7 in wins.
4. **Alakazam's bench-out** — 52 % of its losses, at 17.87 % of the field, with
   supporters left unspent (+30.4) in exactly those games.
5. **Festival Lead's negative seat gap** (−1.1 pp at 11 % of the top-100),
   measured with the seven mirror lists excluded — `festival_lead_5` overlaps
   **60/60** with `deck.csv`.
6. **A5's holdout** — 370 unlabelled lists, never classified.
7. **`MEMORY.md` needs a curation pass** — compacted 19.9 → 18.8 KB tonight with
   every link preserved, still above the 17.1 KB target. Further cuts should be
   steered by hand, not automated at 06:00.
